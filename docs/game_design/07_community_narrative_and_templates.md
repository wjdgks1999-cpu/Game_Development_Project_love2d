# 커뮤니티·서사·템플릿

## 1. 문서 목적

이 문서는 실제 경기 사건을 기사, 커뮤니티 게시글, 댓글, 공식 발언과 등장인물 대사로 변환하는 규칙을 정의한다.

핵심 목표는 다음과 같다.

1. 플레이어가 직접 만든 경기 사건을 사회적 반응으로 되돌려 준다.
2. 실투, 볼넷, 좋은 타자 대응, 수비 실책과 불운을 구분한다.
3. 팬이 알 수 없는 프로그램·능력치·비공개 정보를 노출하지 않는다.
4. 같은 경기에도 비판, 분석, 응원과 현실적인 평가가 함께 나타나게 한다.
5. 커뮤니티 확인이 직접 투구와 성장 흐름을 방해하지 않게 한다.
6. 모든 반응을 오프라인 템플릿 선택만으로 처리한다.

---

## 2. 핵심 원칙

### 2.1 템플릿만 사용한다

- [확정] 실시간 생성형 AI를 사용하지 않는다.
- [확정] LLM, LangChain, LangGraph와 외부 AI API를 사용하지 않는다.
- [확정] 미리 작성한 템플릿을 구조화된 사건 조건에 따라 선택한다.
- [확정] 모든 반응은 인터넷 연결 없이 즉시 선택한다.
- [확정] 같은 경기 로그와 난수 시드에서는 같은 반응을 재현한다.

### 2.2 실제 사건에만 반응한다

- [확정] 발생하지 않은 볼넷, 삼진, 실점과 장타를 언급하지 않는다.
- [확정] 좋은 입력을 실투라고 비난하지 않는다.
- [확정] 수비 실책과 불운을 투수의 명백한 잘못으로 바꾸지 않는다.
- [확정] 결과가 좋아도 실제 제구 문제가 있었다면 이를 지적할 수 있다.
- [확정] 결과가 나빠도 좋은 투구나 수비 불운이 있었다면 이를 구분할 수 있다.

### 2.3 반응은 판정에 영향을 주지 않는다

- [확정] 여론은 능력치, 컨디션과 경기 판정을 변경하지 않는다.
- [확정] 반응은 콜업·강등·재계약 판정을 변경하지 않는다.
- [확정] 휴대폰 확인 여부는 경기와 서사 분기에 영향을 주지 않는다.
- [확정] 반응을 읽지 않아도 여론 단계와 공개 사건 기록은 갱신된다.
- [확정] 플레이어는 게시글이나 댓글을 직접 작성하지 않는다.

## 3. 공개 정보와 비공개 정보

### 3.1 공개 정보

경기 중계, 공식 기록과 구단 발표로 다음을 공개한다.

- 선수명, 나이와 소속 구단
- 1군·2군 등록 상태
- 등판 이닝과 경기 상황
- 경기 전후 점수와 투구 수
- 볼넷, 삼진, 피안타, 피홈런과 실점
- 실제 구종, 구속과 대략적인 투구 위치
- 강한 타구, 빗맞은 타구와 수비 실책
- 강등과 재콜업
- 감독·코치의 공개 발언
- 과거 1군 실패 기록
- 군 복무가 해결되지 않았다는 공개적인 커리어 상황

### 3.2 공개 추론

팬은 경기 장면을 보고 다음처럼 추론할 수 있다.

- 주자가 나간 뒤 흔들린 것 같다.
- 스트라이크 승부를 피한 것 같다.
- 슬라이더가 가운데 몰렸다.
- 포심에 의존하는 것 같다.
- 이전보다 공격적으로 던진 것 같다.
- 결정구가 전보다 나아 보인다.

추론은 “보인다”, “같다”, “오늘만 보면”처럼 단정을 피하는 문장을 사용한다.

### 3.3 공개 금지 정보

- 투수 육성 프로그램과 훈련 퀘스트
- 프로그램 보상과 패시브
- 정확한 능력치·숙련도·멘탈·컨디션·피로 수치
- 플레이어의 릴리스 입력 등급과 목표 지점
- 판정 난수와 재시도
- 비공개 코치 면담
- 타자의 내부 노림수
- 포수의 정확한 사인과 이를 무시했다는 내부 기록

### 3.4 채널별 정보 범위

| 채널 | 사용할 수 있는 정보 |
| --- | --- |
| 기사 | 공식 기록, 로스터 이동, 공개 발언 |
| 커뮤니티 | 공개 기록, 경기 장면, 제한된 팬 추론 |
| 댓글 | 게시글의 공개 사실과 팬 의견 |
| 감독 공식 발언 | 역할 수행과 공개 가능한 구단 평가 |
| 비공개 코치 대사 | 목표·실제 위치, 습관과 기술적 문제 |
| 프로그램 화면 | 내부 경기 로그와 능력치 |
| 주인공 독백 | 감정, 커리어 불안과 프로그램에 대한 생각 |

## 4. 반응 발생 시점과 수량

### 4.1 첫 1군 실패와 강등

- 기사 1개
- 게시글 2개
- 댓글 총 5~7개

볼넷, 연속 볼, 슬라이더 실투, 장타, 피홈런, 리드 상실, 대량 실점, 타자의 좋은 대응, 수비 실책, 빗맞은 안타, 출루 이후 제구 악화와 강등을 사용한다.

기존의 “가능성은 있지만 믿기 어려운 투수”라는 평가가 다시 강화되는 방향을 사용한다.

### 4.2 2군 평가

- [확정] 대규모 팬 반응을 표시하지 않는다.
- [확정] 경기 직후 2군 코치 평가를 중심으로 결과를 전달한다.
- [확정] 2군 훈련, 프로그램 퀘스트와 능력치 성장은 공개하지 않는다.
- [확정] 평가 성공은 재콜업 기사를 통해 간접적으로 알려질 수 있다.

### 4.3 재콜업

- 짧은 기사 1개
- 게시글 1개
- 댓글 3~4개

1군 재등록, 롱릴리프 보직 공백, 과거 실패와 구단의 제한적인 기대를 사용한다. 2군 평가의 상세 투구 로그는 공개하지 않는다.

### 4.4 최종 1군 결과

- 기사 1개
- 게시글 2개
- 댓글 총 6~8개
- 감독 공식 발언 1개

성공 시 리드 유지, 이닝 완료, 삼진, 슬라이더 헛스윙, 위기 탈출, 약한 타구, 출루 이후 회복 등을 사용한다.

실패 시 볼넷, 실투, 장타, 리드 상실, 이닝 미완료, 수비 실책, 불운과 투수 책임을 사용한다.

### 4.5 반응하지 않는 사건

- 프로그램 발현
- 훈련·휴식 선택과 훈련 등급
- 프로그램 퀘스트 결과와 패시브 해금
- 능력치 변화와 체크포인트
- 비공개 코치 면담

## 5. 휴대폰 반응 화면

### 5.1 역할과 표현

주인공의 휴대폰은 기사와 팬 커뮤니티처럼 외부에 공개된 반응을 확인하는 장치다.

- [확정] 게임의 가로 화면을 유지한다.
- [확정] 실제 기기를 세로로 돌리게 하지 않는다.
- [확정] 세로 휴대폰 전체를 작게 표시하지 않는다.
- [확정] 휴대폰 앱 내용을 가로 화면 안의 확대 패널로 표시한다.
- [확정] 세부 크기와 배치는 `08_mobile_ui_art_and_audio.md`에서 확정한다.

화면에는 어두워진 장소 배경, 휴대폰 앱 패널, 시간과 알림, 기사 카드, 게시글, 댓글 펼치기, 읽지 않은 배지와 닫기 버튼을 둔다.

### 5.2 첫 강등의 강제 진입

경기 결과  
→ 감독의 2군 강등 통보  
→ 휴대폰 진동과 알림  
→ 휴대폰 반응 화면 자동 진입  
→ 대표 기사와 첫 게시글 표시  
→ 닫으면 프로그램 발현 장면으로 진행

- [확정] 첫 강등에서만 자동으로 진입한다.
- [확정] 첫 기사 또는 게시글을 즉시 표시한다.
- [확정] 모든 글을 읽도록 강제하지 않는다.
- [확정] 화면 표시 순간부터 닫기 버튼을 사용할 수 있다.
- [확정] 타이핑 애니메이션이나 강제 대기 시간을 사용하지 않는다.

이를 `강제 진입, 강제 체류 없음` 원칙으로 정의한다.

### 5.3 재콜업

재콜업 통보  
→ 휴대폰 알림  
→ `반응 확인` 또는 `다음 일정` 선택

확인하지 않은 반응은 읽지 않은 알림 기록으로 남긴다.

### 5.4 최종 결과

경기 기록과 감독 평가  
→ 휴대폰 알림  
→ `팬 반응 확인` 또는 `엔딩으로` 선택  
→ 생존 또는 군 입대 엔딩

최종 반응을 건너뛰어도 엔딩은 바뀌지 않는다.

### 5.5 즉시 넘기기

- 강제 체류 시간이 없음
- 처음부터 닫기 버튼 활성화
- 모든 댓글을 펼치거나 끝까지 스크롤할 필요 없음
- `남은 반응 건너뛰기`로 다음 장면 이동 가능
- 읽지 않았다는 이유로 보상이나 페널티 없음

### 5.6 기록

- 공개 반응은 휴대폰을 열기 전에 선택한다.
- 확인 여부와 무관하게 같은 로그에는 같은 반응 묶음을 유지한다.
- 읽지 않은 반응은 해당 플레이 경로가 끝날 때까지 다시 확인할 수 있다.
- 경기 중에는 휴대폰을 열 수 없다.
- 비경기 전환 화면에서만 휴대폰 기록을 확인할 수 있다.

## 6. 팬 성향

### 6.1 냉소형

반복된 실패, 군 문제와 재계약 위기를 현실적으로 언급한다. 제한적인 조롱을 사용할 수 있지만 인격·가족·군 복무 자체를 공격하지 않는다.

### 6.2 기록 분석형

볼넷, 삼진, 구종, 구속과 타구를 분석하고 실책과 투수 책임을 구분한다.

### 6.3 응원형

좋은 투구와 불운을 구분해 옹호한다. 실제 긍정 사건이 있을 때만 이를 언급한다.

### 6.4 현실론형

보직, 구단 사정과 재계약 가능성을 냉정하게 평가한다. 성공 후에도 반복 가능한 성과를 요구한다.

### 6.5 감정형

경기 직후의 환호, 분노, 탄식과 제한적인 한국 야구 커뮤니티식 농담을 짧게 표현한다.

### 6.6 혼합 규칙

- 같은 묶음에 최소 3개 이상의 팬 성향을 사용한다.
- 같은 성향을 세 번 이상 연속 배치하지 않는다.
- 성공 반응도 전부 응원형으로 채우지 않는다.
- 실패 반응도 전부 냉소형으로 채우지 않는다.
- 기록 분석형은 실제 언급할 기록이 있을 때만 사용한다.
- 감정형의 밈과 농담은 전체 댓글의 25% 이하를 목표로 한다.

## 7. 여론 단계

### 7.1 익숙한 불안

첫 프롤로그 전 단계다. 가능성은 남았지만 제구가 무너지는 과거를 팬들이 기억한다.

### 7.2 조롱과 체념

첫 실패와 강등 후 단계다. 같은 문제가 반복됐다는 반응과 커리어 위기 논의가 중심이다.

### 7.3 의심 섞인 관찰

재콜업 후 단계다. 변화를 확신하지 않고 이번에는 지켜보겠다는 태도가 중심이다.

### 7.4 제한적인 기대

최종 성공 후 단계다. 달라진 투구를 인정하지만 한 경기만으로 부활했다고 평가하지 않는다.

### 7.5 커리어 종료로 인식

2군 평가 또는 최종 실패 후 단계다. 재계약 실패와 군 입대를 큰 커리어 중단으로 받아들이되 입대 자체를 조롱하지 않는다.

### 7.6 영향 범위

여론 단계는 템플릿 필터, 어조·성향 가중치와 과거 실패 언급 가능성에만 사용한다. 능력치, 멘탈, 훈련, 경기, 콜업과 엔딩에는 영향을 주지 않는다.

## 8. 사건 중요도와 태그

경기 로그 표현과 아래 영문 태그 사이의 표준 매핑은 `contracts/02_game_event_contract.md`를 따른다.

### 8.1 중요도

| 중요도 | 의미 | 예시 |
| --- | --- | --- |
| 0 | 반응 불필요 | 평범한 볼·스트라이크 |
| 1 | 보조 사건 | 삼진 하나, 볼넷 하나, 좋은 슬라이더 |
| 2 | 주요 사건 | 위기 탈출, 장타, 연속 볼넷 |
| 3 | 결정적 사건 | 리드 상실, 강등, 재콜업, 최종 결과 |

- 중요도 0만으로 반응을 만들지 않는다.
- 중요도 1은 보조 소재, 2는 게시글 중심, 3은 기사·대표 게시글 중심으로 사용한다.
- 같은 사건의 여러 태그를 중복 합산하지 않는다.

### 8.2 경기 태그

`walk`, `consecutive_balls`, `strikeout`, `swinging_strike`, `weak_contact`, `hard_contact`, `extra_base_hit`, `home_run`, `lead_lost`, `inning_complete`, `outing_incomplete`, `jam_created`, `jam_escaped`

### 8.3 원인 태그

`release_mistake`, `location_miss`, `slider_hung`, `slider_effective`, `fastball_effective`, `changeup_effective`, `pitch_mix_effective`, `batter_guess_correct`, `batter_good_response`, `pitcher_recovered`, `pitcher_collapsed`

### 8.4 수비·책임 태그

`pitcher_responsible`, `pitcher_not_responsible`, `defensive_error`, `range_deficit`, `bloop_hit`, `bad_luck`, `fielders_choice`, `normal_defense`

### 8.5 커리어 태그

`first_team_failure`, `demoted`, `second_team_evaluation`, `recalled`, `final_success`, `final_failure`, `contract_failed`, `military_ending`

### 8.6 공개 수준

- `public_fact`: 기사와 커뮤니티에 사용 가능
- `public_inference`: 커뮤니티의 추론형 문장에만 사용
- `official_only`: 공식 발언에만 사용
- `private`: 휴대폰 반응에서 사용 금지

## 9. 출력 종류

### 9.1 기사

제목, 1~2문장의 요약, 공개 기록과 필요한 경우 감독 인용문으로 구성한다. 팬 댓글보다 절제된 문체를 사용한다.

### 9.2 게시글

질문형, 비판형, 분석형, 옹호형과 경기 직후 반응형을 사용한다. 한 게시글에는 하나의 중심 사건을 둔다.

### 9.3 댓글

동의, 반박, 추가 기록, 과거 사례, 감정적 반응과 제한적인 농담 역할을 사용하며 게시글과 모순되지 않아야 한다.

### 9.4 감독 공식 발언

공개 가능한 역할 평가, 실제 경기에서 확인한 변화, 남은 과제와 구단 결정을 사용한다.

### 9.5 비공개 대사

목표·실제 코스, 릴리스 문제, 출루 이후 리듬, 포수 사인과 다른 선택, 슬라이더 신뢰도와 다음 역할을 언급할 수 있다.

## 10. 템플릿 스키마와 슬롯

채널별 필드, 댓글 부모 관계, 렌더링 출력 구조는 `contracts/03_community_content_schema.md`를 따른다.

### 10.1 스키마

| 필드 | 내용 |
| --- | --- |
| `template_id` | 고유 ID |
| `channel` | 기사, 게시글, 댓글, 공식 발언 |
| `event_family` | 사건 묶음 |
| `persona` | 팬 성향 또는 화자 |
| `tone` | 긍정, 부정, 중립 |
| `required_tags` | 필수 사건 태그 |
| `optional_tags` | 가중치 상승 태그 |
| `forbidden_tags` | 사용 금지 태그 |
| `allowed_opinion_stages` | 허용 여론 단계 |
| `minimum_importance` | 최소 사건 중요도 |
| `required_slots` | 필수 슬롯 |
| `weight` | 기본 가중치 |
| `cooldown` | 재사용 대기 반응 횟수 |
| `semantic_group` | 유사 의미 그룹 |
| `safety_class` | 일반, 조롱 포함, 민감 소재 포함 |
| `text` | 템플릿 문장 |

### 10.2 허용 슬롯

`{player_name}`, `{team_name}`, `{opponent_name}`, `{inning}`, `{score_before}`, `{score_after}`, `{pitch_count}`, `{walk_count}`, `{strikeout_count}`, `{run_count}`, `{pitch_name}`, `{velocity}`, `{roster_move}`, `{role_name}`, `{result_name}`

### 10.3 슬롯 규칙

- 검증된 구조화 데이터만 삽입한다.
- 자유 입력 문장을 슬롯으로 삽입하지 않는다.
- 존재하지 않는 선수·구단·기록을 만들지 않는다.
- 필수 슬롯이 없으면 해당 템플릿을 제외한다.
- 한국어 조사는 검증된 조사 선택 함수나 조사 포함 슬롯을 사용한다.
- 내부 능력치와 입력 등급은 슬롯으로 제공하지 않는다.

### 10.4 공개 변환

| 내부 정보 | 공개 표현 |
| --- | --- |
| 목표점과 실제점 거리 | 공이 높게 몰림, 바깥으로 빠짐 |
| 멘탈 붕괴 | 주자 출루 뒤 제구가 흔들린 것으로 보임 |
| 타자 노림수 적중 | 타자가 구종을 기다린 듯한 대응 |
| 약한 안타 난수 | 빗맞은 타구가 절묘한 위치에 떨어짐 |
| 수비 도달 실패 | 수비 범위를 벗어난 타구 |
| 패시브 발동 | 공개 반응에 사용하지 않음 |

## 11. 선택 순서

1. 전체 로그에서 공개 가능한 사건만 추출한다.
2. 실제 결정적 사건과 투수 책임을 우선한다.
3. 강등·재콜업·최종 결과 같은 커리어 사건을 반영한다.
4. 볼넷·삼진·슬라이더·실투 등 경기 요약을 보조로 사용한다.
5. 필요한 기사·게시글·댓글 수를 결정한다.
6. 필수·금지 태그, 공개 수준, 여론 단계, 중요도와 슬롯으로 후보를 필터한다.
7. 중심 사건, 팬 성향 다양성, 여론 단계와 최근 사용 이력으로 가중치를 조정한다.
8. 전용 난수 시드로 재현 가능하게 선택한다.
9. 슬롯 삽입 후 기록, 점수, 책임, 공개 정보와 금지 표현을 검증한다.
10. 실패하면 다음 후보, 사건군 범용 템플릿, 안전한 폴백 순서로 대체한다.

사실을 새로 만들어 빈칸을 채우지 않는다.

## 12. 중복 방지

- 같은 템플릿을 같은 묶음에서 두 번 사용하지 않는다.
- 최근 사용 템플릿은 `cooldown` 동안 제외하거나 감점한다.
- 같은 의미 그룹은 한 묶음에 최대 두 개만 사용한다.
- 같은 팬 성향은 세 번 연속 사용하지 않는다.
- 같은 문장 시작 표현을 연속 배치하지 않는다.
- 재콜업 반응에서 과거 실패 언급은 전체의 절반 이하로 제한한다.
- 범용 폴백도 사용 이력과 재사용 대기를 가진다.
- [검증 필요] 전체 선택의 15% 이상이 폴백이면 전용 템플릿을 보강한다.

## 13. 사실과 안전 검증

### 13.1 필수 검증

- 언급한 구종을 실제로 던졌는가?
- 언급한 볼넷·삼진·실점이 발생했는가?
- 리드를 실제로 잃었는가?
- 이닝을 실제로 완료했는가?
- 수비 실책과 투수 책임은 무엇인가?
- 해당 정보가 팬에게 공개 가능한가?

### 13.2 금지 모순

- 실책 실점을 명백한 투수 실투로 단정
- 던지지 않은 구종을 칭찬·비판
- 발생하지 않은 볼넷·삼진·실점 언급
- 리드를 지켰는데 역전을 허용했다고 주장
- 비공개 훈련 성적과 프로그램 보상 언급
- 플레이어의 터치 입력 실패 언급

### 13.3 문장 안전

투구 비판, 보직 평가, 제구 문제와 제한적인 야구 밈은 허용한다.

다음은 금지한다.

- 혐오 표현, 가족·사생활 공격과 위협
- 과도한 욕설
- 군 복무 자체에 대한 비하
- 병역과 관련된 근거 없는 도덕적 단정
- 실제 한국 구단·선수·커뮤니티를 직접 연상시키는 고유 비하어
- 사실이 아닌 범죄와 부정행위 주장

## 15. 등장인물 역할

### 15.1 주인공

커리어 불안, 외부 반응과 실제 투구의 차이, 프로그램에 대한 생각을 짧은 독백으로 전달한다. 실패 엔딩 문장을 직접 전달한다.

### 15.2 감독

강등, 재콜업과 최종 평가를 전달한다. 과거 가능성보다 현재 전력 가치를 중시하고 역할과 기회로 신뢰를 표현한다.

### 15.3 1군 투수코치

첫 실패의 기술적 원인과 출루 이후 반복성, 공격적인 승부를 유지하지 못한 문제를 설명한다.

### 15.4 2군 투수코치

현실적인 훈련 안내자로서 제구, 릴리스와 슬라이더 목적을 설명한다. 프로그램을 알지 못한 채 관찰 가능한 변화에만 반응한다.

### 15.5 포수

짧은 사인과 반응을 제공하고 소극적인 승부를 알아차린다. 최종 등판에서 공격적인 선택을 돕되 플레이어를 강제하지 않는다.

### 15.6 투수 육성 프로그램

경기 로그를 내부적으로 분석하고 훈련 퀘스트와 보상을 표시한다. 미래 정답이나 경기 결과를 제공하지 않는다.

## 16. 주요 서사 장면

### 16.1 첫 등판과 강등

첫 등판 전 포수·1군 코치·주인공 독백으로 상황을 전달한다.

경기 기록  
→ 1군 코치 평가  
→ 감독 강등 통보  
→ 휴대폰 강제 진입  
→ 외부 반응  
→ 주인공의 개인 장면  
→ 프로그램 발현

### 16.2 프로그램과 2군 성장

- 휴대폰과 명확히 다른 UI를 사용한다.
- 프로그램은 목표·실제 위치, 실투와 멘탈 문제를 내부 정보로 표시한다.
- 2군 코치는 같은 훈련을 현실적인 기술 교정으로 설명한다.
- 2군 성장 중 팬 커뮤니티 장면은 삽입하지 않는다.

### 16.3 2군 평가

성공 시 경기 기록, 코치 평가, 보직 공백, 재콜업 통보와 선택 가능한 휴대폰 알림으로 이어진다.

실패 시 경기 기록, 코치·구단 평가, 재계약 실패, 선택 가능한 휴대폰 알림과 군 입대 엔딩으로 이어진다.

### 16.4 최종 1군 등판과 결과

- 포수의 짧은 대사로 과거와 현재를 연결한다.
- 결과가 정해져 있다는 암시를 사용하지 않는다.
- 투구 중 긴 대화나 알림을 사용하지 않는다.
- 결과 후 경기 기록, 감독 평가, 선택 가능한 휴대폰 반응과 엔딩으로 이어진다.

## 23. 완료 기준

- [확정] 첫 강등 후 휴대폰 반응 화면에 자동 진입하고 즉시 닫을 수 있다.
- [확정] 재콜업과 최종 반응은 확인 여부를 선택한다.
- [확정] 휴대폰 확인 여부가 경기와 커리어 판정에 영향을 주지 않는다.
- [확정] 공개 사건만 기사와 커뮤니티에 사용한다.
- [확정] 다섯 팬 성향과 다섯 여론 단계를 구분한다.
- [확정] 사건 태그, 중요도와 책임도로 템플릿을 선택한다.
- [확정] 최근 사용 이력과 의미 그룹으로 반복을 줄인다.
- [확정] 전용 템플릿이 없으면 사실을 만들지 않는 폴백을 사용한다.
- [확정] 같은 로그와 시드로 같은 반응을 재현한다.
- [확정] 총 80개의 초기 템플릿을 준비한다.
- [확정] 선택형 인터뷰 시스템을 구현하지 않는다.
- [확정] 시스템은 인터넷과 외부 AI API 없이 동작한다.
- [검증 필요] 실제 모바일 화면에서 가독성, 반복성과 사실 일치를 확인한다.
