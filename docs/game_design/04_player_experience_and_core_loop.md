# 플레이 경험과 핵심 루프

## 1. 문서 목적

이 문서는 버티컬 슬라이스의 전체 플레이 흐름, 구간별 감정과 학습 내용, 모바일 체크포인트 및 핵심 시스템 사이의 루프를 정의한다.

플레이어는 첫 1군 실패, 투수 육성 프로그램의 훈련 퀘스트, 선택에 따른 성장 여부, 2군 평가와 최종 1군 재도전을 하나의 연결된 경험으로 받아들여야 한다.

## 2. 전체 경험 요약

> [확정] 플레이어는 고정된 첫 실패를 경험한 뒤 훈련 퀘스트를 수행하거나 무시할 수 있으며, 자신이 만든 선수 상태로 결과가 사전에 정해지지 않은 2군·1군 평가 등판에 도전한다.

전체 흐름은 다음과 같다.

```text
짧은 상황 소개
→ 첫 1군 등판과 고정 실패
→ 경기 결과·커뮤니티 반응
→ 2군 강등
→ 투수 육성 프로그램 발현
→ 훈련 퀘스트 제시
→ 행동 기회 1: 훈련 또는 휴식
→ 행동 기회 2: 훈련 또는 휴식
→ 훈련 퀘스트 판정
→ 성장 보상 또는 무보상
→ 2군 평가 등판
├─ 실패: 군 입대 엔딩
└─ 성공: 1군 재콜업
   → 최종 1군 퀘스트
   → 최종 등판
   ├─ 실패: 군 입대 엔딩
   └─ 성공: 생존 엔딩
```

## 3. 경험 설계 원칙

### 3.1 첫 등판만 고정된 실패

- [확정] 첫 1군 등판은 최소 동점 이상의 실점을 허용하는 고정 실패 구간이다.
- [확정] 실패 후 2군으로 강등된다.
- [확정] 실패의 형태, 실점 규모, 볼넷, 장타와 평가는 플레이 내용에 따라 달라진다.
- [확정] 버티컬 슬라이스에서 결과가 고정된 등판은 첫 등판뿐이다.

### 3.2 훈련은 선택이며 성장에는 결과가 따른다

- [확정] 투수 육성 프로그램은 훈련 퀘스트를 제시하지만 훈련을 강제로 실행하지 않는다.
- [확정] 플레이어는 행동 기회마다 훈련 또는 휴식을 선택한다.
- [확정] 훈련을 선택하면 해당 훈련을 직접 플레이한다.
- [확정] 훈련을 하지 않거나 훈련 목표를 달성하지 못하면 퀘스트가 실패한다.
- [확정] 훈련 퀘스트 실패 시 프로그램 추가 성장 보상과 패시브를 받지 못하며, 이미 획득한 일반 훈련 성장은 유지한다.
- [확정] 훈련 퀘스트 실패만으로 게임이 종료되지는 않는다.
- [확정] 훈련 퀘스트 결과와 관계없이 2군 평가 등판에 나간다.

### 3.3 이후 경기 결과는 사전에 고정하지 않는다

- [확정] 플레이어는 2군과 최종 1군 등판의 모든 투구를 직접 조작한다.
- [확정] 게임은 해당 등판의 성공, 실패, 실점과 경기 결과를 사전에 고정하지 않는다.
- [확정] 결과는 플레이어의 선택과 입력, 선수 상태, 타자 대응, 수비 판정과 제한된 난수로 결정한다.
- [확정] 성장하지 않은 선수로도 플레이어가 잘 던지면 평가를 통과할 수 있다.
- [확정] 성장 보상을 받았더라도 실제 등판에서 잘못 던지면 실패할 수 있다.

### 3.4 실패는 실제 커리어 결과로 이어진다

- [확정] 2군 평가 실패 시 군 입대 엔딩으로 종료된다.
- [확정] 최종 1군 퀘스트 실패 시 군 입대 엔딩으로 종료된다.
- [확정] 실패 엔딩 확인 후 해당 평가 등판 직전부터 재시작할 수 있다.
- [확정] 최초 시도와 재시도 결과는 별도로 기록한다.

## 5. 첫 1군 등판

### 5.1 시작 상황

- [확정] 8회 초
- [확정] 주인공 소속 팀이 3:2로 앞선 상황
- [확정] 주자 없음
- [확정] 무사
- [확정] 불펜 소모로 주인공이 한 이닝을 맡는다.
- [확정] 포수 사인과 실제 승부를 통해 기본 조작을 안내한다.

### 5.2 플레이어 목표

표면적인 목표는 한 점 차 리드를 지키고 8회를 끝내는 것이다.

실제 경험 목표는 다음과 같다.

- 낮은 제구와 변화구 신뢰도를 체험한다.
- 출루 이후 멘탈과 입력 안정성이 흔들리는 과정을 확인한다.
- 구종과 코스 선택이 다음 투구에 영향을 준다는 사실을 배운다.
- 목표 코스와 실제 코스의 차이를 이해한다.

### 5.3 고정 실패 처리

- [확정] 최소 동점 이상의 실점을 허용한다.
- [확정] 경기 종료 후 2군으로 강등된다.
- [확정] 실점 과정과 규모는 플레이에 따라 달라진다.
- [확정] 볼넷, 실투, 장타, 좋은 타자 대응과 수비 사건을 구분해 기록한다.
- [확정] 플레이어가 잘못하지 않은 사건을 허위로 투수 책임으로 표시하지 않는다.
- [검증 필요] 좋은 입력을 반복한 플레이어도 고정 실패를 납득할 수 있는지 테스트한다.

고정 실패를 만드는 구체적인 판정 방식은 `05_pitching_match_and_balance.md`에서 정의한다.

## 6. 경기 결과와 2군 강등

### 6.1 결과 화면

플레이어는 다음 정보를 확인한다.

- 최종 실점과 등판 기록
- 볼넷, 피안타와 장타
- 명백한 실투
- 좋은 코스에 대한 타자의 대응
- 수비 실책과 불운
- 출루 이후 멘탈 변화
- 감독과 1군 투수코치의 평가

### 6.2 커뮤니티 반응

- [확정] 첫 등판은 1군 경기이므로 커뮤니티 반응이 발생한다.
- [확정] 반응은 실제 경기 사건에 맞는 템플릿으로 선택한다.
- [확정] 실패 규모에 따라 조롱, 분노, 분석과 제한적인 옹호 비율이 달라진다.
- [확정] 주인공의 과거 실패와 재계약·군 문제를 제한적으로 언급한다.
- [확정] 팬이 알 수 없는 내부 능력치와 시스템 정보는 언급하지 않는다.

### 6.3 강등

- [확정] 감독 또는 1군 투수코치가 2군 강등을 통보한다.
- [확정] 이번 시즌에 개선을 증명하지 못하면 재계약이 어렵다는 사실을 전달한다.
- [확정] 강등 결과 확인 후 첫 모바일 체크포인트를 생성한다.

## 7. 투수 육성 프로그램 발현

### 7.1 발현 시점

- [확정] 2군 강등 후 개인적으로 자신의 투구 기록을 확인하거나 훈련을 고민하는 순간 발현한다.
- [확정] 프로그램의 기원은 설명하지 않는다.
- [확정] 다른 인물은 프로그램을 인식하지 못한다.

### 7.2 프로그램이 보여주는 정보

- 현재 제구 문제
- 슬라이더 숙련도 부족
- 실투 이후 멘탈 회복 문제
- 2군 평가까지 남은 행동 기회
- 훈련 퀘스트 조건
- 성공 보상
- 실패 시 프로그램 추가 보상과 패시브 없이 진행

### 7.3 첫 훈련 퀘스트

퀘스트의 정확한 훈련 종류와 수치 목표는 `06_progression_quest_and_career.md`에서 확정한다.

흐름 단계에서는 다음 원칙만 확정한다.

- [확정] 훈련과 관련된 목표를 제시한다.
- [확정] 완료 기한은 2군 평가 등판 전이다.
- [확정] 플레이어가 훈련을 선택하지 않으면 달성할 수 없다.
- [확정] 훈련을 선택해도 직접 훈련 목표에 실패하면 달성되지 않는다.
- [확정] 퀘스트를 무시하거나 실패해도 일정은 계속 진행된다.
- [확정] 프로그램 발현과 퀘스트 확인 후 두 번째 체크포인트를 생성한다.

## 8. 2군 일정 선택

### 8.1 행동 기회

- [확정] 2군 평가 전 행동 기회는 2회다.
- [확정] 각 행동 기회마다 훈련 또는 휴식을 선택할 수 있다.
- [확정] 실제 훈련 횟수는 0~2회다.
- [확정] 선택하지 않은 훈련 콘텐츠를 강제로 실행하지 않는다.

### 8.2 훈련 선택

훈련을 선택하면 다음 과정으로 진행한다.

```text
훈련 종류 선택
→ 현재 상태와 예상 효과 확인
→ 직접 투구 훈련
→ 목표 달성 판정
→ 일반 훈련 결과 기록
→ 프로그램 퀘스트 진행도 갱신
→ 피로와 컨디션 변화
```

훈련 종류와 효과는 권위 문서인 `06_progression_quest_and_career.md`를 따른다.

- 제구·리듬 훈련
- 슬라이더 완성도 훈련

### 8.3 휴식 선택

```text
휴식 선택
→ 컨디션 회복
→ 피로 감소
→ 훈련 퀘스트 진행 없음
→ 다음 행동 기회 또는 평가 등판
```

휴식은 실패 버튼이 아니다. 낮은 컨디션으로 무리하게 훈련하는 것보다 평가 등판을 준비하는 데 유리할 수 있어야 한다.

### 8.4 퀘스트 정산

행동 기회 2회가 끝나면 훈련 퀘스트를 정산한다.

성공:

- 능력치 성장 보상
- 관련 구종 숙련도 보상
- 조건부 패시브 스킬 해금
- 성장 결과 비교 화면

실패 또는 무시:

- 프로그램 추가 성장 보상과 패시브 없음
- 이미 획득한 일반 훈련 성장 유지
- 조건부 패시브 스킬 해금 없음
- 초기 상태에 가까운 능력치로 평가 등판
- 별도의 인위적인 경기 페널티 없음
- 예정된 2군 평가 등판으로 진행

퀘스트 판정 후 2군 평가 등판 직전 체크포인트를 생성한다.

## 9. 2군 평가 등판

### 9.1 시작 상황

- [확정] 주자 없는 상태에서 한 이닝을 시작한다.
- [확정] 1군보다 낮은 난이도의 타자들을 상대한다.
- [확정] 게임은 성공·실패와 경기 결과를 사전에 고정하지 않는다.
- [확정] 플레이어가 모든 투구를 직접 조작한다.

### 9.2 평가 퀘스트

> [확정] 한 이닝을 완료하고, 투수 책임 실점 없이 볼넷을 1개 이하로 억제하라.

성공 조건:

- 맡은 이닝 완료
- 투수 책임 실점 0점
- 볼넷 1개 이하

실패 조건:

- 투수 책임 실점 발생
- 볼넷 2개 이상
- 교체 등으로 맡은 이닝 미완료

예외:

- 수비 실책만으로 발생한 출루와 실점은 실패 조건에서 제외
- 명백한 불운은 투수 책임 판정과 별도로 기록
- 투수의 실투 이후 발생한 장타는 투수 책임으로 처리

### 9.3 성공

```text
평가 퀘스트 성공
→ 2군 코치의 긍정적 평가
→ 성장 여부와 실제 투구 내용 비교
→ 1군 불펜 공백 발생
→ 재콜업
```

훈련 퀘스트에 실패했더라도 실제 평가 등판에 성공하면 재콜업된다.

### 9.4 실패

```text
평가 퀘스트 실패
→ 실제 경기 기록 확인
→ 2군 코치와 구단 평가
→ 재계약 실패
→ 군 입대 엔딩
```

실패 엔딩 후 2군 평가 직전 체크포인트에서 재시도할 수 있다.

## 10. 1군 재콜업

### 10.1 재콜업 조건

- [확정] 2군 평가 퀘스트 성공
- [확정] 1군 불펜에 일시적인 공백 발생
- [확정] 시스템 훈련 퀘스트 성공 자체는 콜업 조건이 아니다.
- [확정] 실제 2군 등판 결과가 콜업의 근거가 된다.

### 10.2 사회적 반응

- 2군 평가 자체에는 대규모 팬 반응을 만들지 않는다.
- 재콜업 소식에는 제한적인 커뮤니티 반응이 발생한다.
- 기존 실패 때문에 기대보다 회의와 불신이 강하다.
- 훈련 퀘스트와 능력치 변화는 팬에게 공개하지 않는다.

### 10.3 최종 준비

- 최종 경기 상황
- 상대 타순의 성향
- 현재 능력치와 구종 상태
- 컨디션과 피로
- 해금한 패시브 스킬
- 최종 프로그램 퀘스트

위 정보를 확인한 뒤 최종 등판 직전 체크포인트를 생성한다.

## 11. 최종 1군 재도전

### 11.1 시작 상황

- [확정] 8회 초
- [확정] 주인공 소속 팀이 3:2로 앞선 상황
- [확정] 주자 없음
- [확정] 무사
- [확정] 한 이닝을 맡는다.
- [확정] 첫 등판과 다른 타자 구성을 사용한다.
- [확정] 첫 등판의 결과 순서를 반복하지 않는다.

### 11.2 최종 퀘스트

> [확정] 주어진 등판에서 투수 책임으로 팀의 리드를 잃지 않고 임무를 마쳐라.

### 11.3 결과 원칙

- [확정] 게임은 성공·실패, 실점과 경기 결과를 사전에 고정하지 않는다.
- [확정] 플레이어는 모든 투구를 직접 조작한다.
- [확정] 선수의 성장 여부가 실제 판정에 적용된다.
- [확정] 패시브 스킬은 조건을 충족할 때만 적용된다.
- [확정] 숨은 강제 성공이나 실패 보정을 사용하지 않는다.
- [확정] 수비 실책과 명백한 불운만으로 퀘스트를 실패 처리하지 않는다.

### 11.4 성공

```text
리드를 유지하고 임무 완료
→ 감독과 코치가 이전과 다른 투구를 인정
→ 실제 사건을 반영한 커뮤니티 재평가
→ 1군에서 다시 평가받을 기회 확보
→ 조심스러운 희망의 생존 엔딩
```

### 11.5 실패

```text
투수 책임으로 리드를 잃거나 임무 실패
→ 실제 경기 기록과 커뮤니티 반응
→ 재계약 실패
→ 군 입대 엔딩
```

실패 엔딩 후 최종 등판 직전 체크포인트에서 재시도할 수 있다.

## 12. 핵심 게임 루프

### 12.1 전체 버티컬 슬라이스 루프

```text
경기에서 약점 체험
→ 경기 기록과 평가 확인
→ 성장 퀘스트 확인
→ 훈련·휴식 선택
→ 선수 상태 변화 또는 무성장
→ 실제 평가 등판
→ 경기 기록과 퀘스트 판정
→ 콜업 또는 엔딩
→ 최종 위기 재도전
→ 사회적 평가와 커리어 결과
```

### 12.2 일정 선택 루프

- 플레이어의 질문: 평가 전 남은 기회를 어떻게 사용할 것인가?
- 플레이어 입력: 훈련 또는 휴식 선택
- 시스템 처리: 시간 진행, 피로·컨디션·퀘스트 진행도 변경
- 결과: 성장 가능성 또는 상태 회복
- 즉각적 피드백: 예상 효과와 실제 변화
- 장기적 영향: 2군 평가 당시 선수 상태
- 실패 조건: 없음
- 다음 연결: 다음 행동 기회 또는 퀘스트 정산

### 12.3 훈련 루프

- 플레이어의 질문: 어떤 약점을 개선할 것인가?
- 플레이어 입력: 훈련 종류와 직접 투구 입력
- 시스템 처리: 훈련 성과, 능력치 영향, 피로와 퀘스트 진행도 계산
- 결과: 훈련 목표 성공 또는 실패
- 즉각적 피드백: 목표 적중률, 입력 결과와 개선 대상
- 장기적 영향: 퀘스트 보상 및 평가 등판 난이도
- 실패 조건: 훈련별 목표 미달
- 다음 연결: 다음 일정 또는 퀘스트 정산

### 12.4 투구 루프

- 플레이어의 질문: 이 타자와 카운트에 어떤 공을 던질 것인가?
- 플레이어 입력: 구종, 목표 코스와 터치 투구
- 시스템 처리: 실제 위치, 타자 대응과 타구·수비 판정
- 결과: 볼, 스트라이크, 파울, 헛스윙 또는 인플레이
- 즉각적 피드백: 목표 위치, 실제 위치, 입력과 결과 원인
- 장기적 영향: 볼카운트, 멘탈, 피로, 배합과 경기 로그
- 실패 조건: 볼넷, 출루, 투수 책임 실점 또는 임무 실패
- 다음 연결: 다음 투구, 타자 종료 또는 등판 정산

### 12.5 퀘스트 루프

- 플레이어의 질문: 프로그램이 제시한 성장 기회를 수행할 것인가?
- 플레이어 입력: 훈련 선택 또는 무시
- 시스템 처리: 진행도, 기한과 목표 달성 판정
- 결과: 성장 보상 또는 무보상
- 즉각적 피드백: 성공 조건, 남은 기회와 예상 보상
- 장기적 영향: 다음 등판의 선수 능력과 패시브 보유 여부
- 실패 조건: 기한 내 목표 미달
- 다음 연결: 훈련 정산 또는 예정된 평가 등판

### 12.6 평가와 커리어 루프

- 플레이어의 질문: 현재 능력과 조작으로 주어진 역할을 수행할 수 있는가?
- 플레이어 입력: 평가 등판의 모든 투구
- 시스템 처리: 퀘스트 조건과 투수 책임 사건 판정
- 결과: 성공, 콜업 또는 실패 엔딩
- 즉각적 피드백: 경기 기록, 책임도와 코치 평가
- 장기적 영향: 1군 기회 또는 커리어 종료
- 실패 조건: 평가 퀘스트 미달
- 다음 연결: 재콜업, 엔딩 또는 체크포인트 재시도

### 12.7 커뮤니티 반응 루프

- 플레이어의 질문: 내 투구가 외부에서 어떻게 평가되었는가?
- 플레이어 입력: 반응 확인 또는 건너뛰기
- 시스템 처리: 사건 태그, 중요도와 팬 성향에 따른 템플릿 선택
- 결과: 게시글, 댓글과 기사 반응
- 즉각적 피드백: 실제 경기 사건에 대한 사회적 해석
- 장기적 영향: 여론 단계와 다음 반응의 맥락
- 실패 조건: 전용 템플릿 없음
- 예외 처리: 사실을 추가하지 않는 범용 템플릿
- 다음 연결: 강등, 재콜업, 다음 일정 또는 엔딩

## 15. 첫 플레이와 재시도

### 첫 플레이

- 모든 상황 설명과 대사를 기본 속도로 제공한다.
- 튜토리얼 안내를 표시한다.
- 최초 난수 시드와 결과를 별도 기록한다.
- 엔딩 전까지 임의의 구간 선택을 제공하지 않는다.

### 일반 재시도

- 실패한 평가 등판 직전 상태로 복구한다.
- 경기 전 대사와 설명을 건너뛸 수 있다.
- 이닝, 점수, 주자와 상대 타순은 동일하게 유지한다.
- 새로운 난수 시드를 사용한다.
- 재시도 횟수와 결과를 최초 시도와 구분해 기록한다.

### 개발용 재시도

- 동일 난수 시드 또는 새로운 시드를 선택할 수 있다.
- 특정 선수 상태와 퀘스트 결과를 강제로 설정할 수 있다.
- 훈련 성공·실패 경로와 두 엔딩을 직접 시작할 수 있다.
- 개발 기능은 일반 플레이 화면에 노출하지 않는다.

## 16. 플레이타임 관리

### 일반적인 성장 경로

- 목표 시간: 약 40~55분
- 훈련 1~2회 수행
- 2군 평가 성공
- 최종 1군 등판 도달

### 훈련을 모두 건너뛴 경로

- 예상 시간: 약 30~45분
- 훈련 퀘스트 실패
- 프로그램 추가 성장 보상과 패시브 없음
- 능력치·숙련도 성장 없음
- 2군 평가 결과에 따라 진행 또는 엔딩

### 2군 실패 경로

- 예상 시간: 약 25~40분
- 실패 엔딩 후 재시도 시 전체 체험 시간이 늘어날 수 있음

### 시간 조절 원칙

- 투구 수가 많아지면 비핵심 대사와 반응 수량을 축약한다.
- 훈련을 건너뛴 시간을 강제 연출로 채우지 않는다.
- 커뮤니티 반응은 빠르게 넘길 수 있다.
- 재시도에서는 반복 설명을 생략할 수 있다.
